# HJB LAB

**Cognitive Dynamics Series · THEOREM 08**

日本語 | [English](README.en.md)

未来のゴールを終端条件として置き、価値関数と制御方策を時刻 `T → 0` に逆算する教育用Webアプリです。逆算した方策を使って、初期状態から `0 → T` に状態を進められます。画面の地点をクリックすると、その一手の候補操作、環境の流れ、合成した状態変化、現在と未来のコストを比較できます。

定理8で扱われる HJB（Hamilton–Jacobi–Bellman）方程式と動的計画法の関係を、数式・図・操作を通じて学ぶ実験室です。LYAPUNOV LAB、EVOLUTION LAB と共通のヘッダー・フッターを備えています。画面の説明と操作は日本語です。

## ローカルで起動

Python 3 とブラウザを使用します。`index.html` がある `HJB-Lab` フォルダで、次を実行してください。ビルドや外部パッケージのインストールは不要です。

```bash
python3 -m http.server 5175 --bind 127.0.0.1
```

[http://127.0.0.1:5175/](http://127.0.0.1:5175/) をブラウザで開きます。サーバーの停止は `Ctrl+C` です。

## 画面の使い方

1. **未来を設定**：終端の目標を「領域 TCZ(G)」または「点 G」に切り替える。地図上の「ゴール G を移す」で位置も変更できる。
2. **一手ずつ逆算**：「最後の一手を考える」「1手戻す」または「逆算を再生」で、時刻別の価値 `Wₖ(x)` と最善手 `πₖ(x)` を計算する。状態空間の地点をクリックすると候補ごとの合計コストが表示される。
3. **現在から実行**：逆算が完了すると、このタブへ自動で切り替わる。「方策を実行」を押すと、求めた方策に従い、初期状態 `x₀` から時間を進める。終了後の目標までの残り距離も表示される。

STATE SPACEの「2D／3D」で、等高線と立体地形を切り替えられます。時刻・計算済み方策・再生状態は維持します。3Dの高さは選択中の価値 W または負荷 V₀で、見やすさのため `log(1 + 値)` で圧縮しています。同じ実験では時刻間で共通の高さ尺度を使います。図をマウスや指でドラッグすると、左右回転と仰角変更ができます。クリック・タップは地点選択として扱います。視点ボタンと視点リセットも使えます。3Dでも地形のクリックや矢印キーで地点・ゴール・初期状態を変更できます。

軌跡や矢印は、表示中の時刻の地形へ重ねています。軌跡の高さは各地点を表示時刻で評価した値であり、過去の時刻ごとの価値や累積コストではありません。

「価値 W／負荷 V₀」の切替、初期状態・ゴールの移動、期限・終端重み・環境の流れ・負荷・目標半径のスライダーを使えます。変更後は終端から再計算します。数式の色付き項を押すと対応する図を強調します。

## 数理モデルと原式の関係

参照した定理8では、ゴールを **点 `G`** とする終端項 `λ d(x(T),G)²` と、価値関数の HJB 方程式を用います。画面の「点 G」モードはその終端項の形です。「領域 TCZ(G)」モードは、終端項を集合 `D = TCZ(G)` までの距離 `λ d(x(T),D)²` に置き換えた**教材用の拡張**です。図で使う円盤は一般的な TCZ を構成したという主張ではありません。

```text
ẋ = f(x,u,t) = b(x,t) + u
W_N(x) = λ d(x,D)²
Wₖ(x) = min_{u∈U} [ V₀(x,tₖ) Δt + Wₖ₊₁(x + Δt f(x,u,tₖ)) ]
πₖ(x) = argmin_{u∈U} [ 同上 ]
```

`u` は無操作と16方向の速さ1.6の操作。`b(x,t)` は位置と時間によって変わる環境の流れ。`f` は両者を足した**速度**で、一手の移動量は `Δt f` です。コスト `V₀` には中央の高負荷領域と、既定の初期状態付近に置いた固定点からの距離に応じた項を設定しています。これらは計算過程を見せるための人工的なパラメータで、人間の認知の測定値ではありません。

格子は `65 × 49`、`Δt = 0.25`。次状態は Euler ステップで計算し、価値を双線形補間して17個の操作候補を比較します。状態空間から外れる候補は許しません。有限の時間・空間・操作の離散近似であり、連続状態・連続制御の HJB 偏微分方程式の厳密解ではありません。終端ペナルティが有限なので、最適方策でも必ず領域に入るとは限らず、収束や到達後の不変性を保証しません。

逆算で求めるのは価値と方策であり、状態の軌道は時間の順方向に進みます。未来のゴールが現在の方策に影響するのは、ゴールを指定して最適化を行うためです。

関連資料：[苫米地未来原点認知時間理論（定理8、付録A.5）](https://tomabechi.jp/TomabechiTimeTheoryMin6JA.html)。このリポジトリは同論文そのもの、またはその証明を実装したものではなく、同じ形の有限地平最適制御を観察する教材です。

## 動作確認

数値計算の確認には Node.js を使用します。追加パッケージは不要です。`HJB-Lab` フォルダで実行します。

```bash
node tests/solver-check.js
node tests/surface3d-check.js
```

既定条件、短い期限、ゴールの移動、点目標と低い終端重み、逆向きの流れと長い期限の5条件を確認します。価値の有限性、格子点でのベルマン更新、軌道の更新と境界内への保持、ゴール変更による方策の変化を検証します。

ブラウザでは「最後の一手を考える」→「現在まで計算」で「現在から実行」へ自動で切り替わります。「方策を実行」を押して再生します。短い期限では目標に届かない場合があることも、残り距離から確認できます。
